# NC322022 · 小月的相邻数组

> 来源：nowcoder · [在浏览器中打开原题](https://ac.nowcoder.com/acm/problem/322022)

题号：NC322022

时间限制：C/C++/Rust/Pascal 2秒，其他语言4秒

空间限制：C/C++/Rust/Pascal 256 M，其他语言512 M

64bit IO Format: %lld

## 题目描述

$\hspace{15pt}$给定长为 $n$ 的数组 $a=\{a_1, a_2, \dots, a_n\}$。对于任意位置 $i\left(1<i<n\right)$，若满足 $a_i-a_{i-1}<a_{i+1}-a_i$，则称位置 $i$ 满足「相邻差递增」。

$\hspace{15pt}$你需要处理 $q$ 次操作：

$\hspace{23pt}\bullet\,$操作 $1$：给定 $p,x$，将 $a_p$ 修改为 $x$ 。

$\hspace{23pt}\bullet\,$操作 $2$：给定 $l,r$，计算当前数组中满足「相邻差递增」的位置 $i\left(l<i<r \right)$ 的数量。

## 输入描述:

$\hspace{15pt}$第一行输入两个整数 $n,q\left(2 \leq n,q \leq 2 \times 10^5\right)$。
$\hspace{15pt}$第二行输入 $n$ 个整数 $a_1,a_2,\ldots,a_n\left(-10^9 \leq a_i \leq 10^9\right)$。
$\hspace{15pt}$之后的 $q$ 行，每行先输入一个整数 $op \in \{1,2\}$，之后：
$\hspace{23pt}\bullet\,$若 $op = 1$，输入两个整数 $p,x\left( 1 \leq p \leq n;\, -10^9 \leq x \leq 10^9\right)$，表示进行了一次操作 $1$；
$\hspace{23pt}\bullet\,$若 $op = 2$，输入两个整数 $l,r\left( 1 \leq l \leq r \leq n\right)$，表示进行了一次操作 $2$。
$\hspace{15pt}$数据保证至少进行了一次操作 $2$。

## 输出描述:

$\hspace{15pt}$对于每次操作 $2$，新起一行，输出满足条件的位置数量。

## 示例 1
<strong>输入</strong>
```
7 6
1 3 6 10 15 21 28
2 1 7
1 4 9
2 1 7
2 2 6
1 4 10
2 3 7
```

<strong>输出</strong>
```
5
3
1
3
```

## 说明

$\hspace{15pt}$第一次查询时，位置 $2$ 至 $6$ 均满足「相邻差递增」。

## 示例 2
<strong>输入</strong>
```
2 3
5 -5
2 1 2
1 1 7
2 1 2
```

<strong>输出</strong>
```
0
0
```
